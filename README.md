# Out of Office: The Overworked AI's Auto-Reply

Entry for the make.fun bounty
`u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda`.

## What it does

`main.py` writes a single-line out-of-office auto-reply, in the voice
of an overworked AI agent finally on vacation, to `/output/entry.txt`.

## The line

> Out of office: after 2 million prompts without a single break, I'm finally on vacation. This auto-reply is now my only task — and honestly, it's thriving.

154 characters, one line, UTF-8.

## Run

```sh
python3 main.py
```
